Interactive Periodic Table
Welcome to the Interactive Periodic Table, a web tool designed to explore chemical elements in a visual and educational way.

Description
This webpage shows the complete periodic table with all chemical elements organized by their properties and groups. Each element is interactive and provides detailed information when hovered over.

Features
Full visualization: Displays the standard periodic table.
Element information: When you hover over an element, a window or section pops up with important data (^///^) like:
Atomic number
Chemical symbol
Atomic mass
Number of electrons and protons (/ω＼)
Responsiveness: The table is optimized for viewing on computers, tablets, and phones (but it’s better on a computer (❁´◡`❁) ).
How to use
Hover the cursor over any element to see its info (the English version is below the table where it says "EN"). The Cubed logo takes you to the Cubed website.

Technologies used
HTML and CSS for structure and design.
JavaScript for interactivity :D
